# 要望フォームの付け方

作成日　2026年10月4日

要望フォームから送られた内容は、スプレッドシートに1行ずつたまります。届くたびにメールでも知らせが来ます。費用はかかりません。

## 付ける手順（約5分）

1. EdtechChikuhoのアカウントでGoogleドライブを開き、新しいスプレッドシートを作ります。名前は「士業ストック 要望」にします。
2. 「拡張機能」から「Apps Script」を開きます。
3. はじめから入っている `function myFunction(){}` を消して、同じフォルダの `youbou_form.gs` の中身を全部はり付けて保存します。
4. 上の関数の欄で `setup` を選び、「実行」を押します。
5. 「承認が必要です」と出たら、EdtechChikuhoのアカウントを選びます。「このアプリはGoogleで確認されていません」と出たら、「詳細」から先へ進みます。自分で書いたコードを自分の表に付けるときに出る画面です。
6. 実行ログに「送る場所（サイトに入れるURL）」が出ます。このURLをClaudeに伝えます。

## Claudeがすること

- `yobo.html` の `FORM_URL` に、伝えられたURLを入れます。サイトの「要望を送る」ページに「フォームを開く」ボタンが出ます。

## 先に知っておくこと

- 送る人はGoogleにログインしなくても送れます。
- 知らせのメールは、setup を動かしたアカウントに届きます。
